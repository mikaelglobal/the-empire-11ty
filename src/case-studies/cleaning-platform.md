## Project Summary

We designed, developed, and deployed a responsive web platform for a professional cleaning business. 

## Key Integrations

- Customer scheduling and booking database
- Automatic transactional mail alerts (bookings, receipts, and follow-ups)
- Scalable database using MongoDB Atlas

## Outcomes

Our solution automated the client's operations, reducing scheduling administration by over 70% and providing a seamless interface for customers.
