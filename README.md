# the-empire-11ty

A static website built with Eleventy for MIKAEL GLOBAL, featuring case studies, insights, and portfolio content.

## Overview

This project powers a modern, content-driven site with:
- A homepage and about section
- Case studies with project highlights
- Insights/blog-style posts
- Shared layouts, navigation, and styling

## Tech Stack

- Eleventy
- Nunjucks templates
- HTML, CSS, and JavaScript
- Static assets under the src directory

## Development

Install dependencies:

```bash
npm install
```

Start the local development server:

```bash
npm start
```

The site will be available at http://localhost:8080.

Build for production:

```bash
npm run build
```

## Project Structure

- src/ — site content, templates, and assets
- src/case-studies/ — case study markdown files
- src/insights/ — insight/post markdown files
- src/_includes/ — shared layout templates
- src/assets/ — CSS, JavaScript, images, and fonts
